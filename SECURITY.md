# Security Policy

## Supported Versions

The latest release on the `master` branch is the only supported version for
security fixes. Older releases receive security patches on a best-effort basis.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest | :x:               |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead,
report them privately to the maintainer by email at
[kudarap@gmail.com](mailto:kudarap@gmail.com).

Please include as much of the following as possible:

- The affected version(s) and commit hash
- A description of the vulnerability and its impact
- Steps to reproduce
- Any proof-of-concept code

You will receive an acknowledgment within 5 business days, and we will work to
triage and fix the issue. We appreciate responsible disclosure and will credit
you for the report unless you prefer to stay anonymous.
